# 통SKY 1.0.46 운항 노선 검토

확인일: 2026-11-03. 인천 기준, 기존 동북아·한국 제외 범위의 대한항공 61개·아시아나 29개 목적지 총 90개를 대조했다. 현재 운항 확인과 향후 월별 운항 보장은 구별한다.

## 확인한 오류와 수정

- 기존 대한항공 노선 필터가 조회 월의 마지막 날이 2026-12-17 이내일 때만 적용되어, 기간 확대 후 운휴 노선이 다시 검색 목록에 포함되었다.
- 인천↔블라디보스토크·모스크바·상트페테르부르크·이르쿠츠크·두바이는 재개가 확인되기 전까지 제외한다.
- 인천↔멜버른은 공식 공지 기간 2026-12-18~2027-03-14와 겹치는 달만 수집한다. 월 단위 수집이므로 운항 여부에 따라 저장 달력의 날짜를 임의 삭제하지 않는다.
- 동일한 전체 검색 조건에서 1,438개 → 1,314개 노선·월 조회. 기존 대기 목록에도 적용하고 완료 커서를 남은 항목에 맞춰 보존한다.
- 기존 달력·요일 판정·저장 공간·초기화 식별자·공지 닫기 설정은 변경하지 않는다.

## 확인의 한계

현재 지도에 없다는 이유만으로 미래에도 영구 미취항이라고 판단하지 않았다. 취리히의 정확한 2027 시즌, 클락의 통합 후 개별 KE 스케줄, 코타키나발루·보홀·콜롬보·알마티·텔아비브의 미래 자체 운항은 이번 확인에서 확정하지 못했다. 이 항목들의 미래 검색 제외 규칙은 변경하지 않았다. 바르셀로나는 OZ 목록에만 있어 통합 후 KE 편명 확인이 별도로 필요하다.

운항 증거로 좌석 조회 실패, 일반 공항 선택 목록, 공동운항 판매 페이지 또는 항공권 가격 페이지를 사용하지 않았다. 실시간 항공사 전체 날짜 검색을 완료했다는 의미가 아니다.
